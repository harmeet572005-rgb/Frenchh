# Bebu — Boyfriend's Day Website ❤️

Files:
- index.html
- style.css
- script.js
- images/photo1.jpeg ... photo10.jpeg

## Run it
Double-click `index.html` to open it in your browser.

## Music
For the "Perfect" button to play, place a legally obtained copy of the song in this folder and name it:
song.mp3

The browser will not autoplay the music; Bebu has to tap "Our song".

## Free hosting
You can upload this folder to GitHub Pages, Netlify Drop, or another static hosting service.
